# Candidate cut: Pass 1–4

Run passes in order. Never score someone Pass 1 killed.

## Inputs
- Candidate list. Usable brief: profile URL | resume | First Last + current company + target seat. Best: URL + the recruiter's concern on the same line. "That person from the conference" is not a brief; ask.
- `Scorecard_active.md` (the only live rubric) and the search brief.

## Pass 1 — Knockouts (fast, binary)
Default knockouts; replace with the ones in `Scorecard_active.md` when present:
1. Average tenure ≤ 2 years with no explanation
2. No core-domain experience the seat requires
3. Adjacent-but-wrong function (e.g. lead-gen only for a closing role)
4. Wrong geography and no relocation signal
5. Category mismatch (similar-sounding industry that is not the same market)
Record one reason per kill.

## Pass 2 — Evidence check
For survivors, collect proof: numbers, dates, named employers/products, territories, certifications. "Extensive experience" and "team player" count for nothing. Missing evidence = a flag, not a guess.

## Pass 3 — Score
Apply the 9-point card (see `desk-card-scoring`). Mark non-applicable factors N/A, don't penalize.

## Pass 4 — Gate
- 8+ priority · 7+ first-touch after the recruiter names them · 6 recruiter's call · <6 no contact · 9 is rare.

## Output
A desk card. Status: New → Qualified or Rejected.
