# Follow-up sweeps

Run daily against the send log (`send_log.md`: name, seat, sent date, status).

## Who qualifies
Status = Awaiting, no reply on the thread, search not On-hold. Skip anyone Unsubscribed, Rejected, Interested, or Not-now.

## Day 5 (business days after first touch)
Reply on the same thread, same subject. 2–3 sentences: restate the seat in one line, add one new useful detail (comp band if approved, location flexibility, timeline), re-ask. No guilt ("just bumping this").

## Day 10
Last touch. 1–2 sentences. Make "no" easy: "If now isn't the time, a one-word 'no' is fine and I'll close this out. If you know someone who fits, I'd value the name."

## After day 10
No reply → mark Closed-no-reply. No further outreach on this seat.

## Rules
- Draft the sweep as a batch: "N follow-ups ready — approve?" Send only on approval.
- Pause all sweeps for a search marked On-hold.
- Voice rules from `outreach-voice` apply, including banned phrases.
- Log every touch with date in `send_log.md`.
