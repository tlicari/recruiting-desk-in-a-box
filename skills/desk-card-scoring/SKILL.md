# Desk card scoring

## The card (9 points)
`Scorecard_active.md` holds the live rubric. Template:

| # | Factor | 2 | 1 | 0 |
|---|---|---|---|---|
| 1 | Core domain depth | 5+ yrs or ran the function | Some exposure | None |
| 2 | Ownership / field | Founder, owner, or field-facing seat | — | Desk-only |
| 3 | Planning | Budgets, CRM, plans shown | — | Not shown |
| 4 | Technical credential | Cert / degree / 5+ yrs hands-on | — | None |
| 5 | Presenting / enablement | Demos, training, customer-facing | — | None |
| 6 | Implementation | Onboarding, adoption, customer success | — | None |
| 7 | Values fit | FLAG only, never a point from vibes | — | Flag "off" with why |
| 8 | Multi-region | 2+ regions if the seat needs it | — | N/A if local |
| 9 | Breadth | Range the seat needs | — | N/A if specialist seat |

Scores are integers out of 9. Tiers: A = 8–9, B = 7, C = 6.

**Evidence law:** counts = dollars, counts, dates, territories, named employers/products, cert numbers. Doesn't count = adjectives, assumptions ("probably has…").

## Desk card
```
SEARCH: [role] | [geo] | [search code]
IN: [n]   SURVIVORS: [n]   KILLS: [n]

1. [Name]  [score]/9  [A/B/C]  — [one line evidence]
   Flag: [or none]
KILLS
- [Name] — [one reason]
DECISIONS
- Approve first-touch: [names]
- Your call (6/9): [names]
NEXT 15 MIN
- Name them and I produce send pack / packets / both
```

## One-page packet (forwardable, no internal slang)
```
# [Name] — [Target seat]
Score: x/9   Geo: match|stretch|fail   Source: [URL]
Why them — 3 evidence bullets with numbers or named proof
Mapping — domain / territory / tenure (avg + gaps) / role-specific
Risks — honest, one line each
Questions to confirm on a call — 3 only
Do not contact / submit until: [if anything]
```
